CCB Admin Sync

Master-account-only tools.

Spreadsheets

Pick the Master Membership and Register files once — the sync, contacts, and schedule tools below all use these. (The library catalogue reads the Media sheet directly and needs no upload.)

Membership sync — detect

Reconciles the Master + Register against the app's members and returns a tiered worklist. It makes no changes itself — the tools below do the writing. 🛑 items are the ones that actually stop a write, and they're all that locks those tools; ⚠️ and ℹ️ are advisory — worth reading and acting on, but they hold nothing back. If you fix anything in the spreadsheets or the app, just re-run.

Update the Borrowers sheet

Writes this year's cohort back into the app's Borrowers sheet: adds Master members who aren't in the app yet (name + the email or phone found for them + expiry) and updates the expiry of members already there — including the household record a member is kept under, which is listed as such. Anything genuinely unsafe (a near/fuzzy name, a duplicated Master name, a member with no contact detail, or two new people sharing one) is never written and never silently skipped: each is a 🛑 item in detection, so a clean detection means there's nothing to skip. Writes are all-or-nothing. Existing records keep every other field; only the expiry changes, and nothing is ever deleted.

Run Membership sync — detect first — that unlocks the preview. Apply additionally needs a detection with nothing 🛑 blocking.

Gmail Contacts projection

Projects current members into this account's Contacts under the CCB Members label, tagged by class / teacher / level so you can email a whole class from Gmail. Preview shows the planned create / update / remove; only CCB labels and contacts in that umbrella are ever touched. Apply writes to Contacts (not the spreadsheets) and is guarded against oversized diffs.

Run Membership sync — detect first — that unlocks the preview. Apply additionally needs a detection with nothing 🛑 blocking.

Website class schedule

Rebuilds the class-schedule table into a Google Doc with a stable PDF link, from the uploaded spreadsheets only. Teacher/level come from the Register, day/time and enrolment from the Master, and the class list is whatever the data contains. Story Time (children's) classes are detected from the data (Summary "Children" teachers + kids age levels) and use the Story Time capacity; you'll get a ⚠️ warning if those two signals disagree. Capacity isn't in the sheets, so set it here. (Fee and term/weeks are skipped for now.) Reads only — no changes to the spreadsheets.

Library catalogue

Rebuilds the catalogue from the Media sheet into a single Google Doc with a stable PDF link the website can point at.
